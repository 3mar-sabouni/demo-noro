Follow these simple steps to get started and make the most of our app's powerful features!

Step 1: Install & Activate the App

Add the module to your Odoo addons path, update the app list, search for Quick Search, and click Activate.

Step 2: Locate the Search Icon

After installation, a search icon appears in the Odoo top bar (systray) for quick access.

Step 3: Open Global Search

Click the search icon to instantly open Odoo’s Global Search (Command Palette).

Step 4: Search & Navigate Faster

Start typing to search menus, actions, and records. Select any result to navigate instantly - no keyboard shortcuts required.

Step 5: Use on Mobile & Tablet

Ideal for touch devices where keyboard shortcuts like Ctrl+K or Cmd+K are not available.

Frequently Asked Questions

Find answers to common questions about installation, configuration, and using the app. If you don't see your question here, feel free to reach out - we're happy to help!

What does the Quick Search app do?
Quick Search adds a search icon to the Odoo top bar, allowing you to instantly open the global search (Command Palette) with a single click, improving navigation speed and user experience.
Do I need to use keyboard shortcuts to search?
No, Quick Search works with a simple click on the search icon. It is a perfect replacement for Ctrl+K / Cmd+K, especially on mobile and tablet devices.
Is Quick Search mobile-friendly?
Absolutely! Quick Search is fully compatible with iOS and Android devices, making global search easy on touchscreens where keyboard shortcuts aren’t available.
Do I need to configure anything after installation?
No configuration is required. The app works out-of-the-box once installed and activated.
Will this app interfere with existing Odoo functionalities?
No, Quick Search only enhances navigation by providing faster access to global search. It does not affect any core Odoo features or modules.
